# Индекс ячейки

У каждой ячейки появляется адрес: её индекс в организованном списке контейнера. Мировых координат у адреса нет. Положение на экране живёт отдельно и спрашивается по индексу.

Связь представления делает две вещи. По индексу она находит ячейку и её мировое положение. По слоту под указателем она находит индекс этой ячейки. Контейнер по-прежнему хранит только порядок ячеек. Карта держит слоты и индексы, представление контейнера их не ищет.

Карта — отдельный объект с двумя словарями: слот даёт индекс, индекс даёт слот. `Reset` очищает оба. `BindWorldWithIndex` добавляет одну пару. Новая сетка начинается с `Reset`, затем в карту записывается каждый слот. `WorldToIndex` берёт индекс из словаря по слоту. `IndexToWorld` находит слот по индексу и спрашивает у него текущее положение. Пул позже только вызывает `Reset` и заново заполняет карту через `BindWorldWithIndex`.

Вью ячейки сообщает, что в него вошёл указатель, и не знает ни карту, ни курсор. Подписчик наведения спрашивает у карты индекс этого слота и записывает его в курсор. Курсор хранит индекс. Вью-модель отдаёт этот индекс рамке. Рамка по индексу берёт слот из карты и встаёт на него.

Проверка на сцене прямая. Выбор индекса ставит отметку на соответствующую ячейку. Наведение на ячейку возвращает её индекс, и отметка встаёт туда же. Если указатель уходит с ячеек, нового события нет, и отметка остаётся на последней.

Ряд и столбец карта получает из индекса и числа колонок. Это раскладка списка, а не положение на экране. Представление контейнера находится по контейнеру, который оно показывает. Дальше индекс даёт слот и его положение, а слот под указателем даёт индекс.

Курсор уже хранит этот индекс, и рамка за ним следует. Направление, использование ячейки и контекстное меню остаются у контроллеров следующей задачи. Форма этого ввода записана в документе о взаимодействии. Соседние инвентари и вторая сторона здесь не появляются: индекс описывает одну плоскость.
