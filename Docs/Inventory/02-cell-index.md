# Индекс ячейки

У каждой ячейки появляется адрес: её индекс в организованном списке контейнера. Мировых координат у адреса нет. Положение на экране живёт отдельно и спрашивается по индексу.

Связь представления делает две вещи. По индексу она находит ячейку и её мировое положение. По точке на экране она находит индекс ячейки под этой точкой либо сообщает, что под точкой ячейки нет. Контейнер по-прежнему хранит только порядок ячеек. Прямоугольники слотов знает представление, а саму связь держит отдельный сервис.

У сервиса три метода: `WorldToIndex`, `IndexToWorld` и `BindWorldWithIndex`. `BindWorldWithIndex` перезаполняет временную карту, когда вью берутся из пула и связываются с моделью: в неё записывается вью вместе с контейнером и индексом ячейки. `IndexToWorld` спрашивает положение у записанного вью. `WorldToIndex` проверяет, в какой из этих вью попадает точка. Сервис собирается позже, вместе с пулом. Сейчас достаточно отметки, которая показывает уже известный индекс на собранной сетке.

Проверка на сцене прямая. Выбор индекса ставит отметку на соответствующую ячейку. Наведение на ячейку возвращает её индекс, и отметка встаёт туда же. Если указатель уходит с ячеек, отметка остаётся на последней.

Ряд и столбец карта получает из индекса и числа колонок. Это раскладка списка, а не положение на экране. Представление контейнера находится по контейнеру, который оно показывает, и дальше работает прежняя связь: индекс даёт положение слота, точка экрана даёт индекс.

Курсор пока только пользуется этим адресом в следующей задаче. Соседние инвентари и вторая сторона здесь не появляются: индекс описывает одну плоскость.
